# StillMind

**Live app (open in a browser):** https://jodilrigney.github.io/stillmind/

**For ChatGPT to see the whole app, share this visual tour:**

https://jodilrigney.github.io/stillmind/overview.html

or the GitHub page with pictures:

https://github.com/jodilrigney/stillmind/blob/main/public/overview.md

The live site is a JavaScript app. Language models cannot click it or see the pictures it draws on screen. The overview is every screen as screenshot files plus words. Uploading those pictures into ChatGPT is the most reliable way for it to see them.
